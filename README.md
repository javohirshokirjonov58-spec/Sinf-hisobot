# 🎓 Sinf Kassasi - Kassa va To'lovlar Boshqaruvi

Sinf rahbari, o'qituvchilar va ota-onalar qo'mitasi uchun o'quvchilar yig'imlari va to'lovlarini avtomatlashtirilgan holda yuritish tizimi.

## 🚀 Imkoniyatlar

- **📊 Umumiy Hisobot:** Kassadagi pul, qarzlar, to'lov foizi, o'quvchilar ro'yxati va holati.
- **📥 Eksport:** Jadvalni Excel (.xlsx) va CSV formatida yuklab olish.
- **💰 To'lov qabul qilish:** O'quvchini tanlash, tezkor summa tugmalari va to'lov kvitansiyasi (chek).
- **👥 O'quvchilar:** Bittalab yoki ommaviy matn orqali ro'yxatga kiritish, tahrirlash, o'chirish.
- **🕒 To'lovlar tarixi:** Barcha tranzaksiyalarni filtrlash va yuklab olish.
- **⚙️ Sozlamalar & Zaxiralash:** Yig'im summasi va nomini o'zgartirish, bazani JSON orqali zaxiralash (Backup/Restore).
- **🔄 Nollashtirish:** Yangi oy to'lovlari uchun to'lovlarni arxivlab yangilash.

## 🛠️ O'rnatish va Ishga tushirish

1. Kutubxonalarni o'rnatish:
```bash
pip install -r requirements.txt
```

2. Dasturni ishga tushirish:
```bash
streamlit run app.py
```
Yoki Windows foydalanuvchilari uchun `start.bat` faylini ishga tushirish kifoya.
